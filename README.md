A 3D map web application of the University of Information Technology (UIT) combined with 360-degree panoramic photos. Allows students, visitors, and others to quickly search for classrooms, buildings, and directions.

### Key features

- Interact with a 3D model of the school campus.
- Explore the space with 360-degree viewing.
- Look up buildings, classrooms, laboratories, or sports fields. Share and find directions between locations.
- Search for information about the school and bus routes connecting to it.

### How to use

```sh
# 1. Clone the repository
git clone https://github.com/helitoo/uit-imap.git

# 2. Navigate to the folder containing the project's source code.
cd uit-imap

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Access the application at `http://localhost:5173`.
